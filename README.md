# Dhruv Poddar — Interactive Resume

A modern, responsive, web-based resume experience designed to go beyond a traditional PDF resume.

This project transforms a standard resume into a clean digital experience with interactive links, responsive viewing, and direct PDF export while preserving professional resume standards.

## 🌐 Live Website

🔗 https://resume-ol3.pages.dev/

## Features

### Interactive Resume

- Fully web-based resume experience
- Clickable social links
- Clickable certification links
- Direct email access
- PDF export support

### Responsive Design

Optimized for:

- Desktop
- Tablets
- Mobile devices

The resume maintains its original layout while scaling appropriately across devices.

### PDF Ready

Includes print optimization:

- A4 formatting
- preserved colors
- correct spacing
- clean export layout

### Performance

- Lightweight frontend
- Fast loading
- Static deployment
- No unnecessary dependencies

## Running Locally

Clone the project:

```bash
git clone https://github.com/Shin7806/your-repo-name.git
```

Open directory:

```bash
cd your-repo-name
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```
